# Practicum

## Roles

- admin - tizimni boshqaruvchi
- little - faqatgina o'ziga berilgan ruxsatlar bilan cheklanadi. Masalan: can_view_schedules, can_add_schedules
- dean - faqatgina o'zining "faculty" sidagi talaba o'qituvchilarni kuzata oladi. create/update/delete ruxsatlari mavjud emas.
- teacher - faqatgina o'ziga biriktirilgan guruhlarni kuzata oladi, o'sha guruhlar uchun assignmentlar create qilib submissionlarni baholay oladi.
- student - faqatgina dars vaqtida FaceID orqali o'zini tasdiqlay oladi, submission qila oladi.
